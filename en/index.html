PRODUCTION // 100% AI

A game about AI, made by AI

The game's world is about machines that keep fighting a war without people. The game itself was built the same way: code, art, audio, balance and text are all generated by artificial intelligence, from the first line to release.

A human sets the task and signs off on the result. Everything else is done by AI — and we say so up front, not in the fine print.

  • CODE combat loop, economy, saves, shop — in Godot
  • ART biome backdrops, enemies, key art, UI and icons
  • AUDIO sound effects and music
  • BALANCE wave curves, economy, a 160+ node tree
  • TEXT story, interface and localization into 10 languages
